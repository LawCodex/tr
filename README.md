# LawCodex — Türkiye (`tr`)

Legislation of the Republic of Türkiye in force, as plain Markdown, in Turkish — generated from
the official consolidated texts of **Mevzuat Bilgi Sistemi** (https://www.mevzuat.gov.tr),
run by the Presidency of the Republic (Cumhurbaşkanlığı Hukuk ve Mevzuat Genel Müdürlüğü).

*Work in progress — counts are filled in when the conversion is complete.*
